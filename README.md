# simulador_atividade_DIO
Este projeto consiste em um desafio prático da Digital Innovation One (DIO). Simulador de investimentos em Fundos Imobiliários (FIIs), desenvolvido em Excel, com cálculo da capacidade de investimento a partir da renda disponível, projeção patrimonial, estimativa de dividendos e distribuição de aportes por perfil de investidor.
